# 奶油像素原畫資產

2026-10-18，依使用者選定的 B 版「柔和奶油像素」參考圖，使用內建 image_gen 重新繪製透明角色圖稿，並實際接入現有 Canvas 2D。原始 PNG 保存在本目錄，不依賴外部網路。

每張為五欄、六列，共 30 格；欄位依序為幼年、少年、成年待機、成年開心、成年睡眠。共 18 品種、90 格原畫。不要把每張圖片當成單一寵物繪製。

`cream-atlas.ts` 在啟動時解碼本機 PNG，以透明間隙定位每格，移除 alpha < 200 的半透明霧邊，再以 nearest-neighbor 縮成邏輯像素。PNG 原稿不受修改；原稿中透明區的 RGB 可能仍含背景色，應以 alpha 為準。

`main.ts` 載入圖稿後啟動原有刷新流程；`render.ts` 的奶油畫風優先使用原畫，繼續輸出同一個 100×100 RGBA 畫布和 `shapeOf` 點擊遮罩。素材缺失時才使用既有程序化造型備援。既有其他畫風仍使用程序化造型。

蛋保留程序化花紋、seed、裂痕與飛殼動畫；孵化後切換原畫。三成長階段使用各自原畫；幼年／少年睡眠依自身大小縮放成年睡眠格。體型以寬度變形呈現，稀有色與個體毛色以原畫明暗重映射呈現。呼吸、跳躍、圖示泡泡與進化星光仍由現有動畫流程合成。

原畫目前沒有逐幀走路、獨立尾巴或眨眼格；blink／look／stand 共用所處階段的待機格，tired 共用睡眠格，幼年／少年開心用該階段原畫配合跳躍與泡泡。未來增加動畫時應擴充圖格及映射，不混用外觀不同的程序化身體。此處是圖稿動作覆蓋範圍的明確限制。

離線預覽工具 `app/scripts/preview.ts` 解碼相同 PNG 並呼叫同一裁切器，因此預覽與程式內使用的原畫一致。

共用生成規格：以 B 版設計板作為風格參考，暖可可階梯外框、奶油亮部、低飽和暖色、小黑點眼、圓潤動物剪影；五欄六列、每格一隻、朝左側面、透明留白、不含文字／介面／陰影／圖示。各列依上述品種指定花紋、耳型、口鼻、毛量和尾型；各欄依上述生命階段與姿勢指定。生成工具：內建 image_gen；無外部 API 或執行期生成。
