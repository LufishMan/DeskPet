# DeskPet

住在你桌面角落的小寵物。你的電腦越忙，牠吃得越飽、長得越快；你專心工作時，牠就安安靜靜地陪在旁邊。

> **開發中**，目前還沒有可下載的版本。

## 牠是怎麼長大的

- **一開始是一顆蛋**。蛋上的花紋暗藏著裡面是什麼動物：貓、狗、鼠、倉鼠，或是熊。
- **電腦開著，牠就會吃東西**。CPU 越忙，牠吃得越多；電腦休眠或關機時，牠也跟著休息。
- **大約每一到兩週長大一次**：蛋 → 幼年 → 少年 → 成年。
- **體型反映你的使用習慣**：常跑重度運算的人，養出來的寵物會比較圓。
- **心情跟著記憶體走**：電腦很吃緊時，牠也會緊張。
- **每隻都有自己的個性**：有的黏人、有的傲嬌、有的膽小。但牠不會直接告訴你，要你自己慢慢觀察。
- **成年後會留下一顆新的蛋**，你可以選擇延續同一個血脈，或從一顆全新的蛋重新開始。牠的成長紀錄會收進回憶相簿。

放著不管也不會死掉。太久沒開電腦，牠只會變瘦、變得沒精神，回來後多陪陪牠就會恢復。

## 上班也能安心使用

- **預設不出聲、不彈通知、不搶視窗焦點。**
- **老闆鍵**：一個快捷鍵就能立刻隱藏或叫回來。
- **專注模式**：寵物縮到角落，不主動找你玩。
- **全螢幕或簡報時自動隱藏。**

## 怎麼跟牠互動

| 操作 | 效果 |
|---|---|
| 點一下 | 摸摸牠 |
| 連續點 | 搔癢 |
| 按住拖曳 | 把牠抱到別的地方 |
| 滑鼠停在牠身上 | 牠會抬頭看你 |
| 右鍵 | 選單：玩具、回憶相簿、專注模式、隱藏、設定 |

## 隱私與安全

DeskPet 只讀取電腦**整體**的 CPU 和記憶體使用量，**不會**讀取你開了哪些程式、視窗內容或鍵盤滑鼠輸入，也**完全不連網**。所有資料只存在你自己的電腦（Windows：`%LOCALAPPDATA%\DeskPet\`），不需要系統管理員權限。原始碼公開在這裡，任何人都可以檢查。

## 移除

關閉程式後，刪除程式檔和 `%LOCALAPPDATA%\DeskPet\` 資料夾即可。
