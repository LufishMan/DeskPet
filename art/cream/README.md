# 奶油像素原畫

2026-10-18，依使用者選定的 B 版「柔和奶油像素」參考圖，用 ChatGPT 的圖片生成（gpt-image）繪製的透明角色圖稿。檔案內含 OpenAI 的內容來源憑證（C2PA），只記錄生成工具和時間，沒有個人資料。

這個資料夾是**原始圖稿**，不會打包進程式。程式使用的是由這裡烘焙出來的小圖集 `app/src/assets/pets.png`。

|---|---|
| cats.png | 虎斑、英國短毛貓、美國短毛貓、布偶、暹羅、波斯 |

每張五欄、六列，共 30 格；欄位依序為幼年、少年、成年待機、成年開心、成年睡眠。共 18 品種、90 格。每一格是一隻寵物，不要把整張圖當成單一寵物。

## 烘焙圖集

修改原畫後，在 `app/` 下執行：

```
npm.cmd run bake-atlas
```

`app/scripts/bake-atlas.ts` 會：

1. 以透明間隙定位每一列、每一格（容許生成圖幾像素的排列誤差）。
2. 移除 alpha < 200 的半透明霧邊，每格只留最大的連通區。原稿透明區的 RGB 可能仍含背景色，一律以 alpha 為準。
3. 以 nearest-neighbor 縮成邏輯像素：成年待機約 76×62 以內，鼠科和倉鼠縮小。
4. 把 90 格打包成 `app/src/assets/pets.png`，格子座標寫進 `app/src/assets/pets-atlas.ts`。

程式啟動時只解碼這張小圖集（`app/src/cream-atlas.ts`），預覽工具 `app/scripts/preview.ts` 也讀同一張，所以預覽和程式內看到的一致。

## 動作覆蓋範圍

蛋保留程序化花紋、seed、裂痕與飛殼動畫，孵化後切換原畫。三個成長階段使用各自的原畫；幼年和少年睡覺時，依自身大小縮放成年睡眠格。體型以寬度變形呈現，稀有色與個體毛色以原畫明暗重新上色。呼吸、跳躍、圖示泡泡與進化星光由現有動畫流程合成。

原畫目前沒有逐幀走路、獨立尾巴或眨眼格：blink、look、stand 共用所處階段的待機格，tired 共用睡眠格，幼年和少年開心用該階段原畫配合跳躍與泡泡。日後增加動畫時，應擴充圖格和映射，不混用外觀不同的程序化身體。

## 共用生成規格

以 B 版設計板作為風格參考：暖可可色階梯外框、奶油亮部、低飽和暖色、小黑點眼、圓潤動物剪影；五欄六列、每格一隻、朝左側面、透明留白、不含文字、介面、陰影或圖示。各列依上述品種指定花紋、耳型、口鼻、毛量和尾型；各欄依生命階段與姿勢指定。
